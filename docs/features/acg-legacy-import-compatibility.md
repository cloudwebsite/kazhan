# ACG 货源导入兼容

对接部分较旧的 ACG 类货源时，卡栈会对「接口缺失 / 返回异常页」做兼容，避免把真正的缺货、鉴权失败或限流误判成可重试错误。

---

## 站长需要知道的

1. 在 **渠道 / 货源** 添加对应协议连接，填上游地址与密钥，先测连通再导入。  
2. 大目录首次采集可能较慢，属正常；请在货源 **任务** 里看进度，不必反复整批重提。  
3. 个别带复杂规格组合的商品，旧接口可能无法可靠报价，导入会跳过或失败——以任务结果为准，不要手工猜价强行上架。  
4. 已导入成功、或你已锁定/改过价的商品，不会被兼容逻辑随便覆盖。

排查顺序：连通测试 → 任务错误信息 → 上游后台该商品是否仍可售 → [导入任务](../guide/import-tasks.md)。

---

## 边界（摘要）

- 仅在只读报价明确「接口不可用」时走旧版兼容路径；401/403、真实 429、5xx、业务拒绝不会被当成「旧版可替代」。  
- 库存与价格以可校验的响应为准；部分失败不会写成错误的「0 库存」。  
- 现代报价与旧版价格不会在同一商品上混用。
