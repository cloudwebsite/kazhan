# 货源对接（渠道管理）

后台 **渠道管理**（`/channel`）五个页签，覆盖「连上游 → 导入 → 采购履约 → 健康与对账」。

---

![渠道管理](/images/admin-channel.png)

*界面说明：* 五个页签——货源渠道、健康评分、供货账号、采购单、明细对账。「货源渠道」里新增连接、测连通、采集同步与定时计划。

## 页签总表

| 页签 | 权限约 | 作用 |
|---|---|---|
| **货源渠道** | `supply:*` | 连接 CRUD、测连通、采集/同步、定时计划、导入任务 |
| **健康评分** | `supply:read` | 成功率与延迟评分；一键禁源/恢复；自动禁源策略 |
| **供货账号** | `supplier:*` | 下游对接账号；前台申请审核；重置密钥 |
| **采购单** | `procurement:*` | 本站向下游/上游采购履约单状态机与人工补发 |
| **明细对账** | `reconcile:*` | 创建对账任务、差异明细、资金总览 |

系统设置 → 货源：低库存阈值、Host 白名单、对接免审等。  
商品侧二次改价/分类：商品管理。导入任务细节：[导入任务](../guide/import-tasks.md)。

---

## 货源渠道：最短上手

1. **添加连接**：选协议，填上游地址与密钥（动态表单以后台为准）。  
2. **测试连通**，成功后再采集目录或导入。  
3. 勾选商品 → 分类映射 / 加价 → 提交导入；在任务抽屉看进度。  
4. 小额单验证：扣款、上游订单、本站发货状态。  
5. 需要时打开 **定时计划**（全量/增量/仅价格/仅状态等 scope + 时间窗 + 节奏）。

分类与复用发货：[商品导入分类](./product-import-category.md)  
旧版 ACG 兼容：[ACG 兼容](./acg-legacy-import-compatibility.md)

## 协议怎么选

对接 **上游** 时，后台协议类型包括（以你版本下拉为准）：

| 协议代码（概念） | 典型场景 |
|---|---|
| `kazhan` | 对接另一套卡栈 / 本站对外供货协议 |
| `zcard` | 对接兼容该协议的上游站 |
| `dujiao_next` | 对接独角数卡 Next 类上游 |
| `acg_faka` | 对接 ACG 发卡类上游 |
| `kasushou` | 对接卡速售类开放平台 |
| `kayixin` | 对接卡易信类开放平台 |

选错协议会导致签名或路径全部失败。  
本站 **对外供货** 给别人当上游：用本站供货协议与密钥（产品命名中的 `kazhan`），与「我去对接别人」方向相反。详见 [产品命名](../guide/naming.md)。

## 健康评分

- 按近期成功率、延迟合成评分；可看最近错误与样本数。  
- 异常时可 **禁源**（停止走该连接采购），恢复后再开。  
- 可配自动禁源策略，避免持续失败打满重试。

---

## 供货账号（下游连你）

| 能力 | 说明 |
|---|---|
| 手动建号 | 标注协议、发密钥；鉴权侧一套 key 可用于各入站协议 |
| 前台申请 | 用户个人中心提交；待审核列表「通过并开通 / 驳回」 |
| 免审 | 系统设置 → 货源 → 对接免审 |
| 重置密钥 | 泄露后立即重置并通知下游 |

申请资料在审核弹窗一次看清；驳回须填意见。

---

## 采购单

状态含：待处理、已提交、轮询中、已履约、已拒绝、已退款、人工等（界面文案为准）。  
可按订单号深链；有权限时可重试或人工补发详情。付款后未发卡时：先对采购单与上游单，再决定补采或退款。

---

## 明细对账

1. 创建/执行对账 Job（时间范围）。  
2. 查看四态明细与差异标记。  
3. 顶部可看当日资金总览。  
上游若不支持订单列表，任务可能失败并提示「上游不支持列表对账」——改用单号核对。

## 库存与预警

| 能力 | 在哪 |
|---|---|
| 定时同步 / 加速检查 | 货源渠道 → 定时计划 |
| 库存预警阈值 | 系统设置 → 货源 |
| Telegram 等通知 | 系统设置 → 工单/通知通道 |

详见 [低库存监控](../operations/low-stock-monitor.md)。

---

## 常见问题

| 现象 | 处理 |
|---|---|
| 连通失败 | 地址、密钥、IP 白名单、HTTPS 证书 |
| 目录很慢 | 大目录正常；看任务，勿反复重提整批 |
| 部分商品跳过 | 锁定、人工改价、规格不支持、上游不可售 |
| 付了款未发卡 | 查本站订单 + 采购单 + 上游单；是否改成了本地发货却无库存 |
