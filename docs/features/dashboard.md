# 运营概览

后台首页 **运营概览**（`/home`）。用来看一段时间内的成交与毛利，不是改配置的地方。

---

![运营概览](/images/admin-home.png)

*界面说明：* 顶部可选「今日 / 近7天 / 近30天」；四张 KPI 卡看支付额、支付单数、下单数与预估毛利；下方是支付趋势、支付方式分布、流量与待办入口。

## 你能看到什么

| 区块 | 说明 |
|---|---|
| 时间窗 | 今日 / 近 7 天 / 近 30 天（联动 KPI 与环比） |
| KPI 卡 | 订单支付金额、支付订单数、下单数、新用户、预估毛利/成本等 |
| 环比 | 较昨日/前 7 天/前 30 天同时段 |
| 趋势图 | 支付金额、预估毛利、支付订单数 |
| 渠道占比 | 各支付方式成交分布 |
| 热销商品 | 排行可点进订单/商品 |
| 分站对比 | 有分站时的对比表（权限不足可能为空） |
| 导出 | 有权限时可导出当前窗口数据 |

金额单位跟随后台基础货币；库内按「分」汇总后格式化展示。

---

## 怎么用

1. 每天先看「今日」支付额与支付订单数是否异常。  
2. 毛利异常时：查货源采购成本是否未回填（概览可能提示未知成本订单）。  
3. 需要明细时：跳转 [订单管理](./orders.md) 按支付时间筛选。
