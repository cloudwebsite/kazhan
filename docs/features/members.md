# 会员、钱包、充值、提现与礼品卡

---

![钱包管理](/images/admin-wallet.png)

*界面说明：* 账单流水、余额/流水、提现审核、礼品卡。先搜用户再看流水或调账；礼品卡明文仅创建时展示一次。

## 后台入口

| 菜单 | 做什么 |
|---|---|
| **用户管理** | 查会员、启停、指定等级/推荐赠送等级等 |
| **钱包管理** | 账单流水、积分流水、人工调账、提现审核、礼品卡 |
| **系统设置 → 充值 / 提现 / 积分 / 供货充值** | 规则与开关 |
| **支付渠道** | 哪些渠道允许「会员充值」「商品购买」「供货充值」 |
| **营销 → 会员等级** | 会员价折扣与升级规则 |

前台：注册/登录 → 个人中心（充值、订单、礼品卡、提现、工单、奖品等）。

---

## 注册与登录

在 **系统设置 → 安全**：是否允许注册、各场景图形验证码、用户名长度等。  
邮件/短信验证依赖通知通道。详见 [系统设置](../guide/settings.md)。

---

## 钱包管理页签

| 页签 | 作用 |
|---|---|
| **账单流水** | 按用户搜索（用户名/邮箱）→ 看余额与流水；可切换积分流水 |
| **提现审核** | 审核会员提现申请 |
| **礼品卡** | 批次创建；**明文卡密仅创建时展示一次** |

### 人工调账

在账单页对选定用户「调账」：

- 余额：增/扣 + 金额 + **原因**（写入审计）  
- 积分：同样需原因  
- 优惠券：按批次赠送张数  

不要用改库方式补余额。

### 礼品卡

1. 创建批次：名称、面值、数量。  
2. **当场复制/下载明文码**——之后任何接口都不会再返回明文。  
3. 会员在前台兑换入账；后台可看已兑换/未兑换统计。

---

## 会员充值

1. 系统设置 → 充值：开关、最小/最大金额、赠送档位。  
2. 支付渠道勾选允许「会员充值」并启用。  
3. 前台个人中心充值 → 付款 → 到账。先用最小金额测一笔。

---

## 提现

1. 系统设置 → 提现：开关、手续费、收款方式列表。  
2. 会员提交后，管理员在钱包「提现审核」处理。  
3. 链上/第三方出款需人工核对，系统不保证自动打到链上。

---

## 积分

系统设置 → 积分总开关。积分商城兑换若启用，多规格需顾客选规格；库存不足无法兑换。

---

## 与支付、分站

| 场景 | 说明 |
|---|---|
| 余额支付购物 | 支付渠道「余额 / wallet」驱动 |
| 分站月费 | 常见钱包扣款，见 [分站](./subsite.md) |
| 供货账户充值 | 「供货充值」设置 + 支付渠道用途开关 |
