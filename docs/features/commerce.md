# 商品、分类与卡密库存

日常卖货的主路径：建分类 → 建商品 → 导入/录入卡密 → 上架 → 顾客下单自动发货。

---

![商品管理](/images/admin-product.png)

*界面说明：* 左侧分类树，右侧按上架状态与库存状态筛选；可新增商品、进分类管理，并检查货源库存/补货。卡密在「卡密库存」菜单单独维护。

## 后台入口

| 菜单 | 做什么 |
|---|---|
| **分类管理** | 建分类、排序、隐藏分类 |
| **商品管理** | 新建/编辑商品、价格、规格、上下架、发货方式 |
| **卡密库存** | 按商品/规格导入卡密、查看库存、导出、禁用 |
| **订单** | 查单、补发、退款、实体发货等 |

从货源拉商品：见 [货源对接](./supply.md)。

---

## 新建本地商品（最短路径）

1. **分类管理** 建一个分类并保存。  
2. **商品管理 → 新建**：填名称、分类、售价（按元）、库存类型。  
3. 若有多规格：先保存商品，再在规格里分别定价。  
4. **卡密库存** 选择该商品（及规格）→ 粘贴卡密预览 → 确认导入。  
5. 商品设为 **上架**，前台刷新后应能看到。

没有可用卡密不要上架「本地卡密」商品，否则付款后可能无货可发。

---

## 发货方式怎么选

在商品/规格的发货设置里（名称以后台为准）：

| 方式 | 适合 | 注意 |
|---|---|---|
| 本地卡密 | 自己囤的卡密 | 一卡一卖（除非你另有重复发货配置） |
| 每单上游采购 | 货源代发 | 需货源连接正常、余额充足 |
| 重复发货 | 同一内容发给多人 | 可设次数/有效期；带顾客专属填写项的商品通常不能用 |

更细规则：[商品导入分类与复用发货](./product-import-category.md)。

---

## 卡密导入注意

1. 有规格的商品 **必须选对规格** 再导入。  
2. 默认「整行一条卡密」；特殊靓号模式仅在你明确选择时才用。  
3. 预览里的重复、空行会跳过或提示，确认后再写入。  
4. 已售出/已占用卡密不能随便改内容；查看明文通常有独立权限与审计。

---

## 上下架与库存

- **手工上下架**：商品列表操作即可。  
- **自动上下架**：仅部分「全规格上游发卡」商品支持；缺货确认后下架、补货后再上。详见导入分类文中的自动上下架说明。  
- **低库存提醒**：系统设置货源分组 + Telegram 等，见 [低库存监控](../operations/low-stock-monitor.md)。

列表可用「上架状态 + 库存状态」组合筛选，例如「已下架但有库存」便于复盘。

---

## 实体 / 人工等其它类型

若商品类型是实体发货或人工交付：付款后不会自动吐卡密，需在订单里按流程发货或标记完成。前台文案与运费（含到付）以商品编辑页为准。

- [ ] 下一笔小额测试单能自动发货或进入正确人工流程
