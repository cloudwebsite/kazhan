# 营销功能

后台 **营销管理**（`/marketing`）五个页签 + 系统设置里的分销/积分等开关。

---

![营销管理](/images/admin-marketing.png)

*界面说明：* 五个页签——会员等级（会员价）、优惠券、秒杀/促销、抽奖活动、免费领取。会员价按支付比例填写（如 95=9.5 折）；指定用户等级在「用户管理」。

## 页签总表

| 页签 | 权限约 | 做什么 |
|---|---|---|
| 会员等级（会员价） | `memberlevel:*` | 等级、升级条件、支付比例折扣、积分规则 |
| 优惠券 | `coupon:*` | 批次生成、作废、导出、赠送 |
| 秒杀/促销 | `coupon:write` 等 | 秒杀价与限量；促销规则 |
| 抽奖活动 | `lottery:*` | 见 [会员抽奖](./lottery.md) |
| 免费领取 | `freeclaim:*` | 开关、会员门槛、奖池商品 |

内容横幅/文章已独立到 [内容管理](./content.md)。  
指定用户等级在 **用户管理** 操作；会员价折扣在本页「会员等级」配置。

---

## 会员等级

- **折扣**：界面填支付比例，如 `95` = 9.5 折；`100` = 无折扣。  
- **升级条件 / 积分规则**：按表单（如每消费 X 元得 Y 积分）。  
- **对外展示 / 排序 / 启停**：控制前台是否展示该等级名。

---

## 优惠券

1. 创建批次：名称、类型（满减/折扣等）、面值、有效期、适用商品或分类。  
2. 列表可按状态筛选；支持勾选批量删除、导出 CSV、作废。  
3. 可在本页或 [钱包管理](./members.md) 调账弹窗里给用户赠券。  
4. 下单以订单快照为准，事后改券不影响已下单。

---

## 秒杀 / 促销

| 类型 | 要点 |
|---|---|
| 秒杀 | 商品、秒杀价、时间窗、限量、每人限购；与库存锁配合防超卖 |
| 促销 | 范围与规则、起止时间、启停 |

上线前用测试号在时间窗内下一单，确认限量与预占（待付款）行为。

---

## 免费领取

配置总开关、是否要求会员等级，以及奖池内商品/SKU。领取会走真实库存逻辑，测完再对客网公开。

---

## 抽奖

创建活动 → 配奖品与概率 → 预览 → 发布。系统发卡占用真实卡密。完整说明：[会员抽奖](./lottery.md)。

---

## 分销 / 积分（在系统设置）

| 能力 | 位置 |
|---|---|
| 分销 / 邀请返佣 | 系统设置 → 分销设置 |
| 积分总开关 | 系统设置 → 积分 |
| 分站白标 | 分站管理 + 系统设置 → 分站 |

返佣与优惠券、手续费叠加时，先在测试环境算清一笔。

---

## 建议上线顺序

1. 商品与支付跑通  
2. 充值 / 积分  
3. 会员等级价 → 优惠券 → 秒杀 → 抽奖 / 免费领取 → 分销 / 分站  

每开一项用测试号验证。
