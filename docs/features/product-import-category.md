# 商品导入、关键词分类与复用发货

从货源导入商品后，可用关键词自动归类，并按规格选择「继续跟上游买」还是「改用自己的卡密 / 重复内容发货」。

导入进度见 [导入任务](../guide/import-tasks.md)。

---

## 操作入口

- **货源 → 导入商品**：全选、全选搜索结果、仅未导入、清空；搜索时其它分类已选不会丢；锁定商品不可选。  
- **导入窗口 → 自动分类**：关键词 / 排除词、任意或全部匹配，按规则顺序命中；可保存本货源规则，也可单件手工覆盖。  
- **商品管理 → 按关键词分类**：对本站商品预览后批量改分类；保留已手工分类的、跳过锁定；一次最多约 1000 件。  
- **商品管理 → 发货设置**：按规格选择发货来源（见下表）。  
- **商品列表筛选**：可组合「上架状态 + 库存状态」（例如已下架但有库存），便于人工复盘。

目录很大时，加载会走后台任务：可关掉窗口，回来同一货源会接着看进度；完整目录会快照一段时间，提交导入时尽量带上快照编号，避免选太久又整目录重下。

---

## 分类谁说了算

单件本次手工指定 → 已保存的手动分类 → 第一条命中的关键词规则 → 上游分类映射。  
关键词是「包含匹配」（不区分大小写），不是正则。

单件若标记了分类保护，上游同步一般会保留该分类；你在后台批量改分类仍可改掉它。  
批量「指定分类」默认只动本次选中的商品；只有明确保存「整个上游分类映射」才会改默认映射。

分类名长度按 1–100 个字符计（中文也按字符），提交前会校验；过长请缩短名称。

## 发货来源

| 来源 | 内容与库存 | 上游采购 |
| --- | --- | --- |
| 每单上游采购 | 跟原来一样向货源下单 | 每单采购 |
| 我的卡密 | 用本站该规格本地卡密，一条只卖一次 | 缺货也不会自动改回上游 |
| 重复发货 | 同一份内容发给多笔订单；可设有效期和次数上限 | 仅当你明确选「首次自动采购」时买一次 |

重复发货内容可以：手动填写、选历史成功采购内容、或首次付款时采购一次。  
每个规格单独设置。改成「我的卡密 / 重复发货」后，价格与上下架由你维护，上游自动改价 / 库存对账会跳过这些规格。

购物车对「重复发货」规格通常限购一份；服务端还会再拦一道。商品锁定后不能改发货设置，但不影响正常卖货与交付。  
带「顾客专属填写控件」的商品不能配重复发货。

## 重复发货采购卡住时

状态大致是：等待首次采购 → 采购中 → 查原单 → 可重复发放。

| 情况 | 你怎么做 |
|---|---|
| 显示待核实 | 用「核查原采购结果」只查**原上游单**，不要换账号重买顶替 |
| 货源账号与首次采购时不一致 | 先恢复原账号配置再核查 |
| 内容失效 / 到期 / 暂停 | 相关订单等人处理；不会自动整单乱退或偷偷再买一份 |
| 结果不确定 | 不要盲目再点采购；先核对上游后台 |

新内容会开新版本，老订单仍读旧版本内容。次数用完后，超时后又付款的订单也不能超发。

## 自动上下架（可选）

默认关闭。适合「规格全是上游发卡、希望缺货自动下、补货再上」的商品。  
自营卡密、人工发货、本地卡密、重复发货、混合来源一般**不支持**自动管理；改成这些来源时会自动暂停。

怎么开：

1. 商品行点「自动上下架」，或勾选后批量设置。  
2. 也可在选好货源后点「检查该货源库存与补货」（后台跑，离开页面不取消）。  
3. 人工上架 / 下架 / 隐藏会暂停自动管理，避免和系统抢。

规则摘要：

- 缺货下架前会做间隔确认，避免一次抖动就下架；库存未知时不乱改状态。  
- 只有「因缺货被自动下架」且上游又可售时，才自动恢复；隐藏商品保持隐藏。  
- 「补货待上架」列表用于查看：系统观察到从缺货变有货、但仍下架的商品。

更细的库存加速检查与 Telegram 提醒见 [低库存监控](../operations/low-stock-monitor.md)。
