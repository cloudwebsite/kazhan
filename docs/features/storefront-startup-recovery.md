# 商城首屏加载

说明前台打开慢、一直转圈或样式不对时，系统大致怎么表现，以及站长可以怎么排查。

---

## 正常情况

1. 打开商城页时，会先出现中性加载态（不是用假分类 / 假横幅凑出来的页面）。  
2. 服务端注入当前站点的公开配置（名称、主题色等安全字段）；密钥和后台入口不会进公开快照。  
3. 分类、商品列表各自加载；某一块失败可以单独重试，不必整页死等。  
4. 断网恢复或回到标签页时，会尝试刷新目录；一般会保留你正在用的筛选。

---

## 站长排查

| 现象 | 先检查 |
|---|---|
| 一直加载 / 空白 | 服务器 `/health`、反代是否把 API 转到同一站点、浏览器控制台是否有 5xx |
| 颜色/页脚不对 | 主题是否已 **发布生效**；清 CDN/浏览器缓存后再开无痕窗口 |
| 分类空但后台有货 | 分类是否隐藏、商品是否上架、是否看错分站域名 |
| 仅手机异常 | 主题响应式与缓存；可对比电脑浏览器 |

写入类操作（下单等）不会套用「读配置失败自动重试」那套逻辑；支付与发货问题请另查订单与支付渠道。

---

## 开发者备注

通用构建产物不再把构建机上的失败结果写进客户 HTML。  
公开配置失败应返回错误，不能假装「已恢复默认」。  
主题预览草稿只影响带预览令牌的请求，正式访客只看已发布值。
