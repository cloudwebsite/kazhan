# 货源商品媒体落盘与 S3 方案

> 日期：2026-11-12  
> 状态：**P0 已实施**；**转 WebP = P1 已实施**（2026-11-12；编码器 `gen2brain/webp` 无 CGO）  
> 工作根：`重构融合/`  
> 相关代码：`server/internal/mods/supply/cover_fetch.go`、`data_description_media.go`、`data_sync.go`；`server/internal/mods/media/`（素材库 / 本地存储；`Media.storage` 已有 `local|s3` 枚举）  
> 目的：说清「对接商品为何自动下图、何时再下、占盘风险」，给出 **媒体落盘模式开关 + 外链防盗链 + 本地/S3 统一存储 + 落盘转 WebP** 的可实施口径。

---

## 1. 结论（先看这段）

1. **现状**：`collect`（采集 / 勾选导入的内容同步）会对**封面**和**详情 HTML 内图片**（最多 20 张）自动下载到本机 `uploads/<渠道名>/`；`price` / `status` / `listing` / `stock` / `reprice` **不下图**。
2. **上游有更新时**：下次 `collect` 会再走封面/详情图处理；进程内有 URL 缓存，**重启后同 URL 可能再下一份**（随机文件名，无内容去重）→ **确实容易占盘**。
3. **已拍板**：连接级 `settings.media_mode` **三档**（`local` / `remote` / `cover_only`）；**新建连接默认 `remote`**；外链图统一 `referrerpolicy="no-referrer"`；`local`/`cover_only` 做「同 URL 跳过 + sha256 去重」。
4. **S3**：**首期与 media_mode / 去重 / no-referrer 一起做**。落盘抽象为统一后端（本机盘或 S3 兼容）；商品/素材字段在 `driver=s3` 时存**完整公网 URL**；首期仅 **公共读 + CDN**（不做私有桶签名）。
5. **转 WebP（P1 已实施）**：仅在**真正落盘**时（素材上传 / 货源 `local`·`cover_only`）把静图统一编成 WebP，再进 `BlobStore`；与 `media_mode`、S3 正交。开关默认关。
6. **兼容**：已有连接未写 `media_mode` 时仍按 **`local`**（避免突然裂图）；存储驱动未配时仍为 **`local`**；转 WebP 默认关，运维显式打开。

## 2. 现状诊断

### 2.1 何时下图

| 场景 | 封面 | 详情内 `<img>` | 图集 `images` |
|---|---|---|---|
| `scope=collect`（定时采集 / 导入后的内容同步） | 下载落盘（可售时） | 下载落盘（≤20） | 同步路径**不写**图集字段 |
| `price` / `status` / `listing` / `stock` / `reprice` | 否 | 否 | 否 |
| 商品锁定 / `cover_protected` / `description_protected` | 保留本地，跳过 | 保留本地，跳过 | — |

入口：

- 封面：`coverFor` → `downloadCover` → `media.SaveLocalIn`
- 详情：`descriptionFor` 解析 `src` / 懒加载属性 → 同样 `downloadCover`
- 失败 fail-open：下不下来则写回**完整上游绝对 URL**，不阻断同步

### 2.2 为何当初本地下载

1. 上游常给**相对路径**（如 `/assets/cache/images/...`），直接存进本站会在买家浏览器 404。  
2. 部分上游有 **Referer 防盗链**；服务端带上游 Origin 拉取可绕过，浏览器直链外链则容易裂图。  
3. 希望上游挂了/换 CDN 后本站图仍可展示。

### 2.3 占盘与重复下载

| 点 | 现状 | 风险 |
|---|---|---|
| 进程内缓存 | `coverCache[coverDir\|url]` | 仅同进程有效 |
| 落盘文件名 | `randToken() + ext` | **同内容可多份文件** |
| 重启后再 collect | 同 URL 可能再下 | 旧路径若商品字段已换新路径，靠引用回收；回收前盘会涨 |
| 详情图 | 每商品最多 20 张 | 商品多 × 定时 collect → 流量与 IO 压力大 |
| S3 枚举 | `Media.storage` 有 `s3` | **未接线**；货源图也不进素材库引用体系（多为主路径字符串） |

## 3. 目标与非目标

### 3.1 目标

- 运营可按**货源连接**选择：本地下载 / 只存外链 / 只下封面。  
- 选外链时，前后台展示尽量不因 Referer 防盗链裂图。  
- 继续落盘时：**同 URL 不重复下、同内容不重复存**；可选落到 **S3**；可选 **转 WebP**，减轻本机磁盘与带宽。  
- 与现有保护字段、轻量 sync scope、fail-open 语义兼容。

### 3.2 非目标（本方案不做）

- 不把所有历史 `/uploads/` 一次性搬迁到 S3 或批量重转 WebP（可另开迁移任务）。  
- 不保证打得过「签名 URL / Cookie / IP 白名单」类防盗链（那种仍用 `local`/`cover_only`）。  
- 不在切换 `media_mode` / 打开转 WebP 时立即狂删旧文件（交给现有引用 / 无人引用清理）。  
- 不改支付、下单、库存同步逻辑。  
- 不把动图（GIF / APNG / 动 WebP）、SVG、ICO、视频强行压成静图 WebP。

## 4. 方案总览

```text
                    ┌─ media_mode=remote ────────► 只存绝对上游 URL（不下图）
货源 collect 媒体 ─┤
                    ├─ media_mode=cover_only ────► 封面走「落盘管线」；详情图绝对 URL
                    └─ media_mode=local（默认）──► 封面+详情图走「落盘管线」

落盘管线（local / cover_only 的封面，以及后台素材上传）：
  校验/解码 → [可选] 静图转 WebP → sha256 秒传 → 按站点 storage.driver
       ├─ local → data/uploads/...（扩展名多为 .webp）
       └─ s3    → PutObject → 对外 URL（CDN/公网域名）写入商品字段
```

三层正交配置：

| 层 | 配置位置 | 含义 |
|---|---|---|
| **是否下载** | 货源连接 `settings.media_mode` | 跟上游同步策略有关 |
| **下载存哪** | 站点设置 `storage.driver`（全局） | `local` 或 `s3`；素材库与货源落盘共用 |
| **落盘是否转 WebP** | 站点设置 `storage.convert_to_webp`（全局） | 仅影响真正写入 BlobStore 的静图；`remote` 外链不转 |

## 5. 媒体落盘模式（连接级）

### 5.1 字段

- 位置：`supply_connections.settings.media_mode`（string）  
- 缺省 / 非法值：按 **`local`**  
- 后台：货源连接编辑页增加下拉（文案面向运维）

| 值 | 行为 | 适用 |
|---|---|---|
| `local` | 封面 + 详情图下载到存储后端（本机或 S3） | 相对路径多、防盗链严、要断链自持 |
| `remote` | **不下图**；相对路径先解析成绝对 URL 再入库 | 省盘/省流量；上游图稳定可直链 |
| `cover_only` | **只下封面**；详情图绝对 URL | 列表图稳定，详情省盘 |

### 5.2 同步规则

1. 仅 `collect` 受 `media_mode` 影响；价/状态等 scope 仍不动图文。  
2. 仍尊重锁定、`cover_protected`、`description_protected`。  
3. `remote` / 详情侧的外链：必须 `resolveUpstreamURL` 成 `http(s)` 绝对地址后再写入。  
4. 从 `local` 改成 `remote`：**下次 collect** 才改字段引用；旧文件不主动批量删除。  
5. 下载失败继续 fail-open（写可用绝对 URL 或保留旧本地值的现有策略，实现时与现网一致并单测固定）。

### 5.3 默认（已确认）

| 对象 | 定值 |
|---|---|
| **新建连接** | `media_mode=remote`（创建时写入 settings） |
| **已有连接 / 缺省键** | 按 **`local`** 解析（兼容：不因升级突然停下载） |
| 相对路径多 / 防盗链严 | 运维改为 `local` 或 `cover_only` |
| 图床友好、可直链 | 保持 `remote` 或 `cover_only` |

## 6. 外链防盗链（`referrerpolicy`）

### 6.1 做法

对外链 `http(s):` 图片（非本站 `/uploads/`、非已配置的本站 CDN 域名）：

1. 前台各主题商品封面 / 列表图：`<img referrerpolicy="no-referrer">`  
2. 后台商品预览、素材外链预览：同上  
3. 富文本详情：渲染或入库后处理时，给外链 `<img>` 补 `referrerpolicy="no-referrer"`（优先单标签属性，便于局部控制）  
4. 可选：页面级 `Referrer-Policy` 作兜底；**不以**全局关掉所有 Referer 为唯一手段（避免影响统计/部分登录跳转）

### 6.2 边界说明（写进运维提示）

- 只对「看 Referer」的防盗链有效。  
- 签名 URL、鉴权 Cookie、仅允许上游 IP 拉取的图，仍需 `local` / `cover_only`。  
- 主题设置弹窗里已有个别 `no-referrer` 示例，需推广到**商品图统一路径**，避免漏改某一主题。

## 7. 落盘优化（即使继续 `local` / `cover_only`）

### 7.1 同 URL 跳过

写入前：

1. 把上游 cover/详情 src 解析为绝对 URL `U`。  
2. 若本地商品当前字段已是存储路径 `P`，且存在映射「`U` → `P`」且对象仍在（本地文件或 S3 Head）→ **跳过下载**，继续用 `P`。  
3. 映射可落在：连接级内存缓存（现有）+ **持久化**（推荐：按 sha256/URL 键的媒体表或轻量 `settings`/`media` 行；优先复用 `Media.sha256`）。

### 7.2 内容寻址（sha256）

- 下载校验通过后算 sha256；若素材库已有同 hash → **秒传**，只复用 path/URL，`ref_count` +1（货源图若暂不进库，至少按 hash 文件名去重）。  
- `SaveLocalIn` / S3 key 建议：`{prefix}/{sha256[:2]}/{sha256}{ext}` 或等价，避免纯随机名堆垃圾。  
- 换图时：商品字段改指向后，旧对象靠引用计数 / 无人引用清理删除（现有素材删除两段式可对齐扩展）。

### 7.3 详情图预算（保持）

- 继续 `maxDescriptionImages = 20`；超额保留绝对 URL 不下载（现逻辑可保留并单测）。

### 7.4 落盘转 WebP（P1）

与「是否下载」「存哪」正交：**只有进 BlobStore 的静图**才可能转码；`media_mode=remote` 的外链原样入库，不转。

#### 为何要做

- JPEG/PNG 货源图体积大；同内容寻址后仍占空间，CDN 流量也贵。  
- WebP 在同等观感下通常更小；现代浏览器覆盖足够前台商品图场景。  
- 转码放在统一落盘管线，素材上传与货源封面/详情图行为一致，避免两套逻辑。

#### 实现现状（P1）

| 路径 | 行为 |
|---|---|
| 素材 `Upload` | `ValidateAndReencode` → `MaybeToWebP` → `BlobStore.Put` |
| 货源 `fetchCover` | 解码校验 → `MaybeToWebP` → `BlobStore.Put` |
| 编码器 | `github.com/gen2brain/webp`（有损 Quality；WASM 转纯 Go，**无 CGO**） |

#### 配置（建议写入 `storage` 组）

| 键 | 默认 | 说明 |
|---|---|---|
| `convert_to_webp` | `false` | 总开关；关=保持现网原格式落盘 |
| `webp_quality` | `80` | 有损质量 1–100；仅静图有损编码 |
| `webp_skip_if_larger` | `true` | 转完比原文件更大则仍存原格式（避免「越转越大」） |

运维提示：打开后**仅新落盘**生效；历史 JPG/PNG 不自动重转（可另开迁移任务）。

#### 管线位置

```text
下载或上传字节
  → 现有校验（格式白名单 / 像素上限 / 剥离附加载荷）
  → 若 convert_to_webp 且「可转静图」：
       解码 → WebP 有损编码 →（可选）体积不优则回退原字节
  → 以最终字节算 sha256 → BlobStore.Put（ext=.webp 或原 ext）
  → 商品/素材字段写最终 URL（本地 /uploads/… 或 S3 公网 URL）
```

要点：

1. **先校验后转码**；转码失败 fail-open：**落原格式**（货源不阻断 collect；素材上传可记 warn 后仍存原图）。  
2. **sha256 以最终落盘字节为准**（转 WebP 后与原 JPG 不再同 hash，属预期）。  
3. 货源进程内 URL 缓存键仍是 `coverDir|上游绝对 URL`；同 URL 再次 collect 复用已转好的对象，不重复转。  
4. MIME / `Content-Type` / 对象键扩展名与最终格式一致（`.webp` + `image/webp`）。

#### 哪些转、哪些跳过

| 输入 | 行为 |
|---|---|
| 静图 JPEG / PNG / BMP / TIFF 等 | 可转 WebP |
| 已是静 WebP | 默认可跳过重编码（或按质量策略可选重压；首期建议**跳过**） |
| 动图 GIF / APNG / 动 WebP | **跳过**，保动画 |
| SVG / ICO | **跳过**（矢量 / 多尺寸图标） |
| HEIC/HEIF、AVIF 等容器 | 首期：**跳过**或「能解码再转」；解不出则原样/失败策略与现校验一致 |
| 视频 | 不在本开关范围 |

#### 与其它档位组合

| media_mode \ convert_to_webp | 关 | 开 |
|---|---|---|
| `remote` | 外链原样 | 外链原样（无落盘，不转） |
| `cover_only` | 封面原格式落盘 | **仅封面**转 WebP 后落盘；详情仍外链 |
| `local` | 封面+详情原格式 | 封面+详情静图转 WebP 后落盘 |

再叠加 `driver=s3`：转完的 WebP 进桶，字段仍是完整公网 URL。

#### 实现注意

1. 编码器已选定：`github.com/gen2brain/webp`（有损 Quality；无 CGO）。**不要**用只能 Decode 的 `x/image/webp` 做 Encode。  
2. 共用 `MaybeToWebP`：货源 `fetchCover` 与 `MediaRepo.Upload` 都走它。  
3. 单测覆盖：静 PNG→`.webp`；动 GIF 不变；开关关闭；`skip_if_larger`；失败 fail-open。  
4. 前台已能展示 WebP；无需为转码单独改主题。

## 8. S3 对象存储融合

### 8.1 现状（P0 后）

| 项 | 状态 |
|---|---|
| `Media.storage` 枚举 `local` / `s3` | 已有 |
| `BlobStore` + `StoreResolver` + 设置页 `storage` | **P0 已接线** |
| 货源 / 素材上传删除 | **走 BlobStore**；S3 写完整公网 URL |
| 落盘转 WebP | **P1 已接线**（见 §7.4；默认关） |

### 8.2 站点级存储配置

放在站点设置组 `storage`，与货源 `media_mode` 正交：

| 键 | 说明 |
|---|---|
| `driver` | `local`（默认）\| `s3` |
| `endpoint` | 兼容 S3 API 的 Endpoint（含 MinIO / OSS / COS / R2） |
| `region` | 区域；部分厂商可填默认 |
| `bucket` | 桶名 |
| `access_key` / `secret_key` | 密钥（密文存储 / 回显脱敏） |
| `force_path_style` | MinIO 等常需 `true` |
| `public_base_url` | 对外访问前缀（可走 CDN）；**完整公网 URL** = `public_base_url + key` |
| `prefix` | 对象键前缀，如 `uploads` |
| `convert_to_webp` | 是否落盘转 WebP（§7.4；P1） |
| `webp_quality` | WebP 质量（P1） |
| `webp_skip_if_larger` | 转完更大则保留原格式（P1） |

### 8.3 统一存储接口（实现口径）

```text
type BlobStore interface {
  Put(ctx, key, body, contentType) (publicURL or /uploads/ path, error)
  Exists(ctx, key) (bool, error)
  Delete(ctx, key) error
  // 可选：SignedURL（私有桶二期）
}
```

- `local`：现有 `StorageRoot` / `/uploads/` 静态路由不变；字段仍可为 `/uploads/...`。  
- `s3`：`PutObject`；商品 `cover` / 详情 `src` / 素材对外 URL **一律存完整公网 URL**（`public_base_url` + key），不经本站反代。前台用「本站 `/uploads/` + 已配置 `public_base_url` 域名」识别本站媒体。  
- 货源落盘、后台上传、外链导入（`ImportFromURL`）全部走同一 `BlobStore`。  
- `Media.storage` 写入实际驱动；删除时按 `storage` 分支删本地或删对象。

### 8.4 与 `media_mode` 的组合

| media_mode \ driver | local 盘 | s3 |
|---|---|---|
| `remote` | 不占本机盘、不占桶 | 同左 |
| `cover_only` | 仅封面占盘 | 仅封面占桶（本机几乎不占图） |
| `local` | 封面+详情占盘 | 封面+详情占桶（**多商品采集时优先推荐此组合**） |

运维选型一句话：

- **最省本机盘且图要自持**：`media_mode=local` + `driver=s3` +（可选）`convert_to_webp`  
- **最省一切存储**：`media_mode=remote`（依赖上游与 `no-referrer`；无落盘则 WebP 开关无效）  
- **折中**：`cover_only` +（可选）`s3` +（可选）转 WebP 只压封面

### 8.5 安全与运维

1. Endpoint / 公网 URL 做 SSRF 校验：上传与货源下载客户端继续用现有 `httpx` 安全客户端（禁内网）。  
2. 密钥不进任务 payload、不进前端明文回显（只回显「已配置」）。  
3. 切换 `driver`：新上传走新后端；旧对象不自动搬迁；提供可选「后台任务：按 Media 表迁到 S3」（二期）。  
4. 同机多站点：`prefix` 按站点隔离；桶可共享。  
5. 对接品牌：设置页可写「S3 兼容 / 阿里云 OSS / 腾讯云 COS / MinIO」等**对接方名称**（业务选型说明，非本产品出处）。

### 8.6 分期

| 期 | 范围 |
|---|---|
| **P0（已实施）** | `media_mode` 三档 + 新连接默认 `remote` + 外链 `no-referrer` + URL 缓存 / sha256 去重 + **`BlobStore` + 站点 S3 配置** + 素材上传/删除与货源落盘走同一存储；S3 字段存完整公网 URL；公共读 + CDN |
| **P1（已实施）** | **落盘转 WebP**：`convert_to_webp` / `webp_quality` / `webp_skip_if_larger`；素材上传与货源落盘共用；动图/SVG/ICO 跳过；转码失败落原格式 |
| **P2（后续）** | 私有桶签名 URL；历史本地文件迁桶 / **批量重转 WebP**；素材库与货源图统一引用计数 |

## 10. 验收标准

### 10.1 P0（已对齐实现）

1. 新建货源连接后 `settings.media_mode` 为 `remote`；`collect` 只写绝对上游 URL，本机/桶无因同步新增对象。  
2. `media_mode=cover_only`：仅封面新增对象；详情图为绝对 URL 且带 `no-referrer`（Referer 防盗链场景抽检）。  
3. `media_mode=local`：可落盘；**连续两次 collect 同 URL 不新增第二份文件/对象**。  
4. `driver=s3`：上传与货源落盘进桶；库内为完整公网 URL；前台可直接打开；引用为 0 时可删对象。  
5. 轻量 scope 与内容保护字段行为不变。  
6. 未配置 S3 时全站仍纯本地；旧连接无 `media_mode` 时仍按 `local` 下载。

### 10.2 P1（转 WebP）

1. `convert_to_webp=false`：行为与现网一致（原格式落盘）。  
2. 打开后：静 JPEG/PNG 新落盘为 `.webp`；动 GIF 等仍为原格式；字段 URL/MIME 一致。  
3. `webp_skip_if_larger=true` 时，转完更大则仍存原格式。  
4. 转码失败不阻断货源 collect（fail-open 落原图或上游 URL，与现策略一致）。  
5. `media_mode=remote` 时无转码、无新增对象。
