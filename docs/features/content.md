# 内容管理

后台 **内容管理**（`/content`）两个页签：

![内容管理](/images/admin-content.png)

*界面说明：* 「文章管理」发公告/帮助文；「首页横幅」配 Banner。可管理栏目、筛选已发布/草稿。

| 页签 | 用途 |
|---|---|
| **文章管理** | 公告、帮助、博客等文章；可分类、发布/下架 |
| **首页横幅** | 首页头图/中通/底栏等 Banner（具体坑位随主题） |

权限：`content:read` / `content:write`。

---

## 文章 / 公告

1. 新建文章：标题、正文（富文本或 Markdown/HTML 编辑器）、类型（如公告）。  
2. 发布后前台公告弹窗/列表才能看到（主题若关闭公告区则不展示）。  
3. 系统设置里「顶部自定义按钮」可链到某篇文章或公告。

插入视频请用 HTTPS 直链或本地 MP4，并注意反代上传大小与超时。

---

## 首页横幅

1. 上传或从素材库选图，设链接、排序、启停。  
2. 保存后刷新商城首页检查各主题是否按预期展示。  
3. 与 **系统设置 → 推荐位** 可同时影响首页；改完做一次实机预览。
