# 工单管理

后台 **工单管理**（`/ticket`）是客服工作台；前台会员/游客在个人中心或独立入口提交工单。

---

![工单管理](/images/admin-ticket.png)

*界面说明：* 默认「进行中」视角；可按待回复/处理中/已解决/已关闭筛选，并按订单号查询。详情里会话回复；内部备注仅后台可见。

## 列表与筛选

| 项 | 说明 |
|---|---|
| 状态 | 默认「未关闭」（待回复 + 处理中）；也可看已解决 / 已关闭 |
| 类型 | 售前 / 售后 |
| 订单号 | 关联订单检索 |
| 优先级 | 普通 / 高 / **已加急**（付费加急由系统设置工单分组控制） |
| SLA | 加急工单有时限；超时会高亮 |

已加急工单由后端排序置顶。

---

## 会话详情

打开「详情」后是会话流：

- 用户消息：左侧  
- 客服回复：右侧  
- **内部备注**：仅后台可见（需工单读权限），不会发给用户  

可回复、标记处理中/已解决/关闭（需 `ticket:write`）。关闭后前台一般不可再追问（以后台状态机为准）。

---

## 与系统设置的关系

在 **系统设置 → 参数设置 → 工单 / 通知通道**：

- 加急费用、是否允许游客工单等  
- Telegram / 机器人：新工单、回复提醒等事件开关  

邮件通知若已配 SMTP，可与工单事件一起测。详见 [系统设置全览](../guide/settings.md)。

---

## 客服日常流程

1. 打开工单管理，先处理「已加急」与 SLA 将超时的。  
2. 售后单核对关联订单与发卡记录，必要时去订单页补发。  
3. 需要财务调账时转有钱包权限的同事，并在内部备注写清原因。
