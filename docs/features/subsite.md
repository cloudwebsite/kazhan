# 分站（白标）

分站 = **同一套卡栈**下，用不同域名展示各自站名 / Logo，卖主站货并可加价。  
适合加盟、分销换皮；**不适合**两家要完全独立账本、密钥、支付商户号的店（那种请用 [同机多站点 · 多实例](../guide/multi-site.md)）。

---

## 和多实例有什么区别

| | 分站（本文） | 多实例 |
|---|---|---|
| 进程 / 安装 | 一套 | 每站一套 |
| 数据库 | 同一库，按分站行隔离 | 建议分库 / 分目录 |
| 超管 / 进货 | 统一 | 各自独立 |
| 密钥 | 共用进程密钥 | 可完全分开 |

---

## 站长怎么开

1. 先按 [部署指南](../guide/deploy.md) 装好**一个**主站，配好域名反代（须正确传递 `Host`）。  
2. 后台打开 **分站 / 经销** 相关菜单（系统设置里也有「分站」分组）。  
3. 为分站分配域名（或从域名池选前缀）、站名、外观。  
4. 会员可在前台自助开通分站时：按页面提示支付月费（钱包余额扣款；月费为 0 表示免费不过期）。  
5. 分站可在允许范围内设置默认加价比例；例外加价一般只到商品级。

到期后该域名通常回落到主站规则（以当前后台设置为准）。

---

## 运维注意

1. 反代必须把访客域名原样传给后端（`Host`）。  
2. 主站「站点地址」与分站域名都要公网可达，支付回调才稳定。  
3. 分站不是物理隔离：备份、升级都是整站一次。  
4. 产品不做「一库一 schema / 一租户一库」；强隔离请改多实例。

更多选型对比见 [同机多站点](../guide/multi-site.md)。
