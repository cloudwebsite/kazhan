# 两步验证与账号恢复

后台可为管理员开启两步验证（TOTP，如 Google Authenticator）。  
绑定后，登录需要：密码 →（图形验证码，若已开）→ 动态码。

---

## 如何绑定

入口：**系统设置 → 安全 → 当前账号两步验证**，或右上角头像 → **账号安全**。

1. 输入当前密码，生成二维码。  
2. 用验证器扫码（或手动输入密钥），在时限内填 6 位动态码确认。  
3. **立刻保存**页面出示的 10 个恢复码（只显示一次）。  
4. 绑定成功后，旧后台会话会失效，需重新登录。

未确认、取消或过期的扫码不会改变原登录方式。

---

## 手机丢了 / 动态码一直错

先排查：是否扫了正确账号、手机与服务器时间是否同步、是否等下一组 30 秒码。连续失败会锁定约 15 分钟。

| 当前情况 | 做法 |
|---|---|
| 还有未使用的恢复码 | 登录页选「使用恢复码」，登录后立刻换绑 |
| 恢复码也丢了，但其他管理员能进后台 | 请有权限的同事在「员工管理」解绑 TOTP |
| 唯一管理员被锁在外，有服务器权限 | 用下面的 `admin reset-2fa` |
| 以上都没有 | 联系有服务器权限的人执行恢复；登录页无法绕过 |

### 用恢复码

1. 账号密码通过后，到动态码步骤点「使用恢复码」。  
2. 输入一个**未使用**的 20 位恢复码。  
3. 进入账号安全 → 更换验证器 → 保存**新**恢复码。  

每个恢复码只能用一次；不要只存在绑定验证器的同一部手机上。

### 其他管理员协助

员工管理 → 目标账号 → **解绑 TOTP**。操作者要验证**自己的**密码/动态码，并填写原因。被重置账号用原密码登录后再绑新验证器。

### 服务器命令行强制解绑

**一键脚本 / 手动二进制：**

```bash
cd /opt/kazhan
sudo ./kazhan admin reset-2fa --username 管理员登录名 --conf /opt/kazhan/configs --dry-run
sudo ./kazhan admin reset-2fa --username 管理员登录名 --conf /opt/kazhan/configs
```

**Docker Compose（在仓库根目录，沿用原项目名）：**

```bash
docker compose -f deploy/docker-compose.yml exec kazhan \
  /kazhan admin reset-2fa --username 管理员登录名 --conf /app/configs --dry-run
docker compose -f deploy/docker-compose.yml exec kazhan \
  /kazhan admin reset-2fa --username 管理员登录名 --conf /app/configs
```

先 `--dry-run` 核对配置路径与数据库，避免解错站。成功后用原密码登录并重新绑定。

SQLite 相对路径按**当前工作目录**解析，请在安装目录执行。

---

## 密码也忘了

两步验证重置**不会**改密码。在同一安装目录执行：

```bash
./kazhan admin reset-password --username 管理员登录名 \
  --password '新的强密码至少8位' --conf /实际安装目录/configs
```

命令行密码可能进 shell 历史；用完建议改一次。若密码与验证器都丢了，两种重置都要做。

---

## 安全提示

- 动态码约 30 秒一变；服务器需时间同步。  
- 密码与动态码各自连续失败会锁定一段时间。  
- 不要删除数据库或改数据加密密钥来「绕过」登录。  
- 回滚旧程序前确认数据库备份匹配；认证相关表结构变更后不能随便降级空跑。
