# 问题反馈

使用中的故障、安装失败、支付/货源对接、文档勘误和功能建议，请到 GitHub Issues 提交：

[打开反馈（选择模板）](https://github.com/cloudwebsite/kazhan/issues/new/choose)

| 你遇到的情况 | 用哪个模板 |
|---|---|
| 宝塔插件、一键脚本、装站向导、在线更新或回滚失败 | 安装与更新 |
| 站已装好：前台、后台、发卡、订单、会员报错 | 运行故障 |
| 收款不到账、货源导入或上游发货失败 | 支付与货源 |
| 文档步骤过时、链接失效、和界面不一致 | 文档问题 |
| 希望增加或改进功能 | 功能建议 |

提交前请先看对应文档：[部署指南](guide/deploy.md) · [支付总览](payment/README.md) · [货源对接](features/supply.md) · [在线更新](operations/update.md)。

安装包在 [Releases](https://github.com/cloudwebsite/kazhan/releases)。请下载具名文件（如 `kazhan-linux-amd64`），不要把 Source code 压缩包当作安装包。

**不要**在 Issue 里粘贴：数据库密码、后台账号、支付密钥、货源密钥、卡密、买家联系方式、Cookie 或 Token。日志请先打码。
