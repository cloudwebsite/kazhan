# 装完先配这些

安装向导结束后，按下面顺序在后台点一遍，站点才能正常卖货收款。  
后台地址默认：`https://你的域名/admin`（或 `http://服务器IP:端口/admin`）。

菜单对照见 [后台菜单对照](./admin-map.md)；更全的分组说明见 [系统设置全览](./settings.md)。

---

## 1. 站点基础（必做）

路径：**系统设置 → 参数设置 → 站点基础**

| 项 | 怎么填 |
|---|---|
| 站点名称 | 顾客看到的店名 |
| 站点地址 | **公网完整网址**，如 `https://shop.example.com` |
| Logo | 可选；从素材库选择 |
| 后台安全路径 | 可选；如 `/manage-8x2k`。保存后立即跳到新入口，原 `/admin` 关闭——**务必记牢** |

支付回调、登录跳转都依赖「站点地址」。写成内网 IP 或 `http`/`https` 不一致，容易付了款不回调。

---

## 2. 支付渠道（要收款就必做）

路径：**支付渠道**

1. 添加渠道，选驱动（虎皮椒、支付宝、微信、UPay、Stripe…）。  
2. 填密钥，勾选用途（购买 / 会员充值等），保存并**启用**。  
3. 用小额单验收到账。

→ [支付总览](../payment/) · [渠道字段手册](../payment/channels.md) · [虎皮椒](../payment/payment-xunhupay.md)

---

## 3. 商品与卡密（本地卖货）

| 步骤 | 在哪 |
|---|---|
| 建分类 | **分类管理** |
| 建商品 | **商品管理** |
| 导入卡密 | **卡密库存**（有规格要选对规格） |
| 上架 | 商品列表 |

→ [商品、分类与卡密](../features/commerce.md)

---

## 4. 货源对接（可选）

**渠道 / 货源** → 添加连接 → 测连通 → 导入 → 看任务。  

→ [货源对接](../features/supply.md) · [导入任务](./import-tasks.md)

---

## 5. 通知（强烈建议）

**系统设置 → 邮件短信 / 通知**：

- SMTP：订单邮件、游客邮箱查单  
- Telegram / 企业微信 / 钉钉：管理员告警、低库存  

先点 **测试发送**。→ [系统设置全览 · 通知](./settings.md)

---

## 6. 安全（强烈建议）

1. 管理员强密码  
2. 后台登录验证码  
3. 绑定两步验证并保存恢复码  

→ [两步验证与账号恢复](../operations/security-2fa.md)

---

## 7. 会员充值 / 提现（按需）

系统设置打开充值/提现规则，支付渠道勾选对应用途。  

→ [会员与钱包](../features/members.md)

---

## 8. 外观主题（可选）

**系统设置 → 模板 / 主题自定义**：改完要 **发布生效**。  

→ [主题概览](../themes/)

---

## 9. 备份（上线前必做）

备份配置、密钥、数据库、上传目录。  

→ [备份与密钥](../operations/backup.md)

---

## 自检清单

- [ ] 前台能打开，后台能登录  
- [ ] 站点地址是顾客实际访问的公网域名  
- [ ] 至少一种支付方式测试到账  
- [ ] 有可售商品与库存（或货源映射正常）  
- [ ] 测试单一笔订单发货成功  
- [ ] 已做完整备份
