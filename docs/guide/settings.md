# 系统设置全览

后台左侧 **系统设置**。页面分 **外层五个页签**；日常改业务开关在「参数设置」里的左侧/顶部分组。

![系统设置：参数设置 · 站点基础](/images/settings-overview.png)

装完站请先按 [装完先配这些](./first-config.md) 走一遍必选项。菜单总览见 [后台菜单对照](./admin-map.md)。

---

## 外层页签

| 页签 | 作用 |
|---|---|
| **参数设置** | 站点、模板、交易、安全、充值、通知等业务参数（下文分组表） |
| **货币** | 展示货币代码、符号、小数位、对基础货币汇率；启用/排序 |
| **审计日志** | 操作审计（谁改了什么）+ 安全审计（登录/取货等） |
| **数据清理** | 按保留天数勾选预览并清理过期数据（需 `dataclean` 权限） |
| **系统更新** | 在线检查版本、更新与回滚；详见 [在线更新](../operations/update.md) |

可用 URL 深链：`/settings?tab=currency` / `audit` / `data-clean` / `update`。

---

## 怎么改才生效

| 类型 | 说明 |
|---|---|
| 多数业务开关 | 点「保存更改」后立即生效（前台可能需刷新） |
| 主题外观 | 主题自定义里还要 **发布生效**，仅存草稿前台看不到 |
| 站点地址 / 支付密钥 | 保存后建议立刻下一笔测试单验证回调 |
| **后台安全路径** | 保存后 **立即跳转** 到新入口，原 `/admin` 关闭；务必记牢新路径 |

## 参数设置 · 分组对照

以下为「参数设置」内当前可见分组（文案以你后台为准）。

### 站点基础 `site`

| 项 | 作用 |
|---|---|
| **后台安全路径** | 如 `/manage-8x2k`；留空则用启动配置默认 `/admin` |
| 站点 Logo | 从素材库选择 |
| 站点名称 | 前台顶栏、邮件标题等 |
| robots.txt 自定义规则 | 追加规则（默认已放行并指向 sitemap） |
| SEO 标题 / 关键词 / 描述 | 搜索与分享摘要 |
| 顶部自定义按钮 | 外部链接 / 文章 / 公告 |
| **站点地址** | 顾客访问的公网完整 URL（含 `https://`） |
| Bing / Google 站长验证码 | 站长平台 meta |

**坑：** 站点地址写成内网 IP、少了 `https`、或多了后台路径，都会导致支付回调失败。

### 模板 `template`

默认商城主题、分类导航样式、每行/每页数量等。外观细节见 [主题](../themes/)。业务开关仍在其它分组，不要指望只靠主题包打开。

### 推荐位 `promo` / 页脚配置 `footer`

顶部/导航推荐、页脚文案链接。横幅素材也可在 [内容管理](../features/content.md) 维护。

### 交易 `trade`

游客查单是否需要查询密码、下单相关规则。改完用游客测试单验证「下单 → 查单 → 取货」。

### 工单 / 通知通道 `ticket` · `notify`

工单加急费等规则；本页下方还有 Telegram / 机器人通道配置。邮件 SMTP、短信、企业微信/钉钉等同属通知体系——务必先点 **测试发送**。详见 [工单管理](../features/tickets.md)。

### 安全 `security`

允许注册、各场景图形验证码、用户名最小长度、两步验证入口。详见 [两步验证](../operations/security-2fa.md)。服务器时间不准时 TOTP 会失败。

### 运维 `ops`

安装状态等内部项，日常少改。

### 充值 / 供货充值 / 提现 / 积分

| 分组 | 用途 |
|---|---|
| 充值 | 会员余额充值开关、金额上下限、赠送档位 |
| 供货充值 | 货源账户充值规则 |
| 提现 | 开关、手续费、可用收款方式 |
| 积分 | 总开关与规则 |

金额库内多以「分」存储；表单一般按「元」。详见 [会员与钱包](../features/members.md)。

### 分销设置 `affiliate` / 分站 `reseller`

邀请返佣；分站主站域名、开通方式、免审、月费等。见 [营销](../features/marketing.md) · [分站](../features/subsite.md) · [同机多站点](./multi-site.md)。

### 货源 `supply`

低库存预警阈值、部分上游 Host 白名单、对接免审等。见 [货源对接](../features/supply.md) · [低库存监控](../operations/low-stock-monitor.md)。

### 对象存储 `storage`

本地或 S3 兼容；MinIO 常需 Path-Style。上传默认在工作目录 `data/uploads/`。

### 前台工具 `tools`

批量二维码、Cookie 工具等前台小工具开关。

### 邮件短信

SMTP（含 SSL/TLS、STARTTLS）、短信签名模板。DKIM 在发件域名 DNS 配置，与 SMTP 连接方式分开。

### 客户代码

客服嵌入脚本、统计代码等；只粘贴可信来源。

### 语言货币 `i18n`

默认语言、启用语言列表、**基础货币**（记账依据）。展示用货币明细在外层「货币」页签维护；跨币支付还取决于渠道能力。

---

## 货币页签（外层）

![货币管理](/images/settings-currency.png)

| 能力 | 说明 |
|---|---|
| 新增/编辑货币 | ISO 代码、符号、前缀/后缀、小数位、汇率、排序、启用 |
| 基础货币 | 默认结算货币；其汇率固定为 1 |
| 与支付关系 | 仅支持 CNY 的驱动在基础货币非 CNY 时可能拒收 |

改货币前请备份并暂停收款核对。

---

## 审计日志 / 数据清理

| 页签 | 谁用 | 注意 |
|---|---|---|
| 审计日志 | 排查「谁改了设置/敏感操作」 | 需 `audit:read` |
| 数据清理 | 按保留天数预览后执行 | 执行不可随意；先预览再确认 |
