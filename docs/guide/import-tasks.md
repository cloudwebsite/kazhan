# 货源导入任务

从上游货源批量导入商品时，系统会立刻返回一个**后台任务**，不必一直开着导入页面。

---

## 站长怎么用

1. 在 **渠道 / 货源** 里选好连接，预览并勾选要导入的商品。  
2. 确认分类映射、加价等参数后提交导入。  
3. 到该货源的 **任务** 入口查看进度、成功/跳过/失败原因。  
4. 网络闪断可以稍后回来看同一任务，一般**不必重新整批提交**（相同请求会按去重键处理）。

### 常见现象

| 现象 | 说明 |
|---|---|
| 新商品暂时没上架 | 常要等库存确认完成；待定价/不可售会保持下架 |
| 部分商品被跳过 | 可能已锁定、人工改过价、或货源配置中途变更 |
| 任务暂停 | 账号/汇率/映射/启停等配置变了，需检查后确认继续 |
| 删不掉货源 | 仍有待执行或进行中的维护任务时会禁止删除 |

同一货源同一时间通常只跑一个维护类导入任务；采购下单不走这个队列。

---

## 运维提示

- 任务与明细保存在数据库；异常退出后可由新进程在租约过期后接续。  
- 超时、网络抖动会有限次重试；认证失败类错误会停住等人处理。  
- 停止任务会保留已成功部分；库存失败的重试范围以任务说明为准。  

更细的分类映射与「复用发货」策略见 [商品导入分类与复用发货](../features/product-import-category.md)。
