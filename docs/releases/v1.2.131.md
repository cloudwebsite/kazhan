# 卡栈 v1.2.131

发布日期：2026-11-11

## 前台工具与 2FA

- 工具中心与各工具页统一大气视觉壳（氛围、轻透面板、主按钮）。
- 2FA：双栏布局、动态码/下一个码、二维码、批量导入导出、加密备份；忘记安全密码可清空本机与账号仓（登录态先删库）。
- 依赖增加前端 `jsqr`（二维码截图导入）。

## 主题安装修复

- 修复「安装显示成功但未落盘 / 列表不出现」：同 hash 残留损坏目录不再被误判为已安装；损坏 `current` 可回退可用版本；Windows 下正确覆盖 `current` 指针。

## 其它

- 分销申请页按钮样式与内容宽度热修。

## 升级说明

请使用完整发行包更新服务端（含内嵌前后台）。主题包 `release/themes/*-1.2.131.zip` 需后台重新上传并启用。升级前请备份数据库与配置。
