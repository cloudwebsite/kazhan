# 卡栈 v1.2.122

发布日期：2026-11-11

## 前台工具中心

- 新增 `/tools` 工具中心与多项纯前端工具：卡密处理、Cookie、行解析、FB 年份、邮箱格式、2FA/TOTP 等。
- 后台设置目录增加 `tools.*` 开关与导航项；主题设置可控制工具/2FA 导航显示。
- 服务端增加工具模块与用户 TOTP 保险库迁移（可选云端同步）。

## 前台主题

- 精仿主题源码纳入 `storefront-themes/`；各主题 App 支持工具导航与路径放行。
- 主题打包版本对齐发行号 `1.2.122`（`release/themes/*-1.2.122.zip`）。
- 移除旧 skins 注册表路径，统一主题 overlay 构建。

## 其它

- 分站/提现等相关前台与后台体验小调整随本版一并发布。

## 升级说明

请使用完整发行包更新服务端（含内嵌前后台）。启动时自动执行迁移；升级前请备份数据库与配置。若站点已安装可切换主题 ZIP，请重新上传并启用 `1.2.122` 主题包以获得工具导航。
