# 卡栈 v1.2.118

发布日期：2026-11-10

## 货源导入

- 导入预览支持按上游分类、商品名关键词缩小拉取范围；可先只拉分类树再选型。
- 后台导入弹窗增加分类多选与关键词输入，分页目录与选型范围互斥，避免大目录误翻页。

## 卡速售对接

- 采购适配器按官方「基础数据 / 商品 / 订单」补齐：`goods/attach`、`goods/pricelog`、`order/list`、`order/complain`。
- 兼容入站 Host 同步暴露上述路径；订单列表支持单号精确查与时间窗分页。
- 撤单表单回调、商品变更通知验签/解析对齐官方表单签名口径。

## 升级说明

请使用完整发行包更新服务端（含内嵌前后台）。启动时自动执行迁移；升级前请备份数据库与配置。
