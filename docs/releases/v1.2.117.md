# 卡栈 v1.2.117

发布日期：2026-11-09

## 移除短信接码

- 移除前台接码购买、订单接码页，以及后台「渠道管理 → 接码任务」。
- 移除接码相关 API、定时任务与货源适配逻辑；通知类短信不受影响。
- 三方言迁移删除 `sms_intents` / `sms_operations` / `sms_retail_quotes` 表，以及商品/订单项/货源连接上的接码专用列；并清理 `product_kind=sms_channel` 商品。
- 保留 `product_kind` / `delivery_kind`，社交服务等其他交付类型继续可用。

## 安装与部署

- 安装向导数据库说明改为：SQLite 支持行级分站，正式高并发推荐 PostgreSQL。
- 宝塔 / Nginx 反代示例改为 `location ^~ /`，避免面板默认 `js|css` 静态规则抢走 `/assets` 导致安装页资源 404。
- 安装守门与 SPA 兼容 `/install/` 相对资源路径回落到根 `/assets/`。

## 其他

- 迁移遇到重复列（如手工加过 `quantity_tiers`）时更稳健恢复。
- Release 产物继续仅包含二进制、`update.json` 与 `SHA256SUMS`。

## 升级说明

请使用完整发行包更新服务端（含内嵌前后台）。启动时自动执行迁移；升级前请备份数据库与配置。若站点经宝塔反代，请确认 Nginx 使用 `^~` 反代整站，否则安装页或静态资源可能仍 404。
