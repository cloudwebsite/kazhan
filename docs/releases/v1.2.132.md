# 卡栈 v1.2.132

发布日期：2026-11-12

## 货源媒体落盘、S3 与转 WebP

- 货源连接新增媒体落盘三档：`remote`（新建默认）/ `cover_only` / `local`；旧连接缺省键仍按本地下载兼容。
- 站点对象存储：本地盘或 S3 兼容（公共读 + CDN）；素材上传与货源落盘共用 `BlobStore`，S3 写入完整公网 URL。
- 可选「落盘转 WebP」（默认关）：静图有损压缩；动图 / SVG / ICO 跳过；转完更大或失败则保留原格式。
- 前后台外链图补 `referrerpolicy=no-referrer`，减轻 Referer 防盗链裂图。

## 后台运营台视觉

- 列表页统一页面壳（页头说明、内容卡分层、筛选条与表格空态）。
- 默认主题改为深蓝旗舰；新增旗舰明/暗与暖色运维预设。
- 登录页与首页仪表布局整理；订单/用户/工单等状态色统一语义映射。

## 前台工具

- 二维码批量工具支持打包下载 ZIP。

## 升级说明

本版无需新增数据库迁移。请使用完整发行包更新服务端（含内嵌前后台），升级前备份数据库与配置。对象存储与转 WebP 为可选配置，默认行为与升级前兼容（旧连接仍本地下载；未开 S3 / 未开转 WebP 时仍写本地原格式）。
